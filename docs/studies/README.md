# Estudos da configuração inicial

Esta pasta resume a preparação necessária para começar o LexisApp. Cada arquivo explica um assunto completo e pode ser lido sozinho.

## Ordem sugerida

1. [Ferramentas básicas](01-ferramentas-basicas.md): Git e editor de código.
2. [Flutter e Dart](02-flutter-e-dart.md): ferramentas que constroem o aplicativo.
3. [Preparação do Android](03-android.md): Android Studio, Android SDK, emulador e aparelho físico.
4. [Preparação do Linux](04-linux.md): suporte a aplicativo de computador no Ubuntu.
5. [Verificação do ambiente](05-verificacao-do-ambiente.md): como descobrir o que está pronto ou faltando.
6. [Situação atual do projeto](06-situacao-atual-linux-android.md): resultado da análise feita neste repositório.
7. [Fundamentos de Dart sem jargões](07-fundamentos-de-dart.md): o mínimo da linguagem para começar a desenvolver o aplicativo.

## Objetivo desta preparação

Ao final, a mesma interface Flutter deve abrir no Linux e em um aparelho ou emulador Android. Nesta primeira fase não é necessário ter banco de dados, conta, internet ou inteligência artificial. O objetivo é somente confirmar que as ferramentas conseguem construir e abrir o aplicativo.
